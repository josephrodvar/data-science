# template_local_data

Template for analyzing an already-in-hand local file: a CSV/parquet you
drop into `data/raw/`, no API involved.

Ships with a small synthetic sample (`data/raw/sample_counts/data.csv`) —
made-up daily subway station ridership counts, not real MTA data — so the
notebook runs immediately with zero setup. Copy this folder as the starting
point for a new local-data analysis and swap in your own file.
